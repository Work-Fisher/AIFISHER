文生图 https://developers.openai.com/api/reference/resources/images/methods/generate
curl https://api.openai.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A cute baby sea otter",
    "n": 1,
    "size": "1024x1024"
  }'

图生图 https://developers.openai.com/api/reference/resources/images/methods/edit
curl https://api.openai.com/v1/images/edits \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Create a lovely gift basket with these four items in it",
    "images": [
      "iVBORw0KGgoAAAANSUhEUgAA...",  // 这是 body-lotion.png 的 Base64 字符串
