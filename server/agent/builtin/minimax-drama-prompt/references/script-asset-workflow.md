# 剧本资产工作流

角色、场景与道具提示词统一使用随官方技能加载的《统一角色与场景资产模板》，不再维护另一份角色示例或默认四宫格步骤。

先读取剧本、人物小传与场次，整理用户需要的资产清单。每个角色登记中文名、统一英文名、身份年龄、外观服饰、首次出场及造型编号；同一造型复用，换装或年龄变化另建编号。场景登记时间、位置、陈设、材质与空间锚点，默认空镜无人。缺少关键事实列为待确认。

默认交付提示词：角色为 9:16 单人完整全身资产，场景为 16:9 空镜。提示词主体按统一模板完整填写，并按该模板的角色/场景格式分别输出。用户确认资产范围及图像生成费用后，才调用原图像生成流程；只有实际成功产出的图片才分配 Picture 编号。人物仍走官方角色资产工作流，场景沿用已选的图像服务，不因共用模板更换调用线路。

图片确认后再做图片编号、参考绑定和后续文戏分段。用户只要求提示词时不创建生成任务，不把模板里示例人物当作本剧人物。
