# 已确认格式示例

本例示范剧本流或多张独立人物参考图场景的 15 秒成品格式、镜头密度和末帧连续性。不得复制人物与台词。段标题是交付分隔，不属于复制进 MiniMax 的提示词正文。只有单张图片时改读 [single-image-flow.md](single-image-flow.md)。

## P01｜15秒｜身份露馅

<Subject1>Jiang Chi是<Picture 1>保留参考图中的面部特征、发型、服装、身材比例、眼镜（如有）以及整体外貌。
<Subject1>，S1 永远是说话人。S1始终使用一种固定的声音：20岁女性，中音偏低，音色明亮带一点沙哑；常态语速偏快、音量偏大、句尾利落，慌乱时起句卡住、尾音发虚，放松时恢复直给；禁止夹子音、娇嗲和播音腔。

<Subject2>Lu Shi Yan是<Picture 2>保留参考图中的面部特征、发型、服装、身材比例、眼镜（如有）以及整体外貌。
<Subject2>，S2 永远是说话人。S2始终使用一种固定的声音：20岁男性，中低音，音色清冷干净；常态语速平稳偏慢、音量克制、句尾收得短，紧张时起句略迟但音量不抬高，放松后语气更低更简洁；禁止播音腔、霸总气泡音和夸张冷漠腔。

<Subject 3>是白天男生宿舍场景。

人物站位：白天的男生宿舍，机位沿书桌与门口形成的轴线拍摄。Jiang Chi以长发少女外形坐在画面左侧电竞椅上，穿宽大的男士T恤，双腿交叠，双手横握手机；Lu Shi Yan站在画面右后方门口，右手端牛奶，正看向Jiang Chi。桌面没有可读文字，只有电脑风扇与手机游戏音效。

[Shot 1]
Jiang Chi中近景。她的拇指在屏幕上连续点按，身体跟着游戏节奏向前压，皱着眉冲手机发火：
<Subject 1> (S1) says:
<d>[Chinese]打野你会不会？龙都不要？</d>
最后一个字落下时，她把手机拍上桌面。

[Shot 2]
门口过肩中景。手机撞桌的声音还没散，Jiang Chi抬头看见门口的Lu Shi Yan。Lu Shi Yan没有走近，只把视线落向她仍交叠的双腿，平静开口：
<Subject 2> (S2) says:
<d>[Chinese]Jiang Chi，把腿合上。</d>
Jiang Chi嘴角一扯，头已经转回桌面：
<Subject 1> (S1) says:
<d>[Chinese]合个屁，我在自己寝室。</d>

[Shot 3]
Jiang Chi近景。话音刚落，她低头看见自己的身体。刚才撑开的肩膀慢慢收住，双腿僵在原位，握手机的手停在桌边；眼睛从胸前移到宽大衣摆，呼吸卡住。

[Shot 4]
双人中景。Jiang Chi缓慢抬头看向Lu Shi Yan，嘴唇张开却只挤出一句：
<Subject 1> (S1) says:
<d>[Chinese]操。</d>
Lu Shi Yan仍端着牛奶站在门口，眉眼没有变化。末帧停在两人的对视和Jiang Chi尚未合拢的双腿上。
