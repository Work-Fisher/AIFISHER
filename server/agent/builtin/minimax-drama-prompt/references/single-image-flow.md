# 单图流：从一张图片推演 10–15 秒文戏

仅在用户没有提供完整剧本、主要依靠一张参考图生成剧情与台词时读取本文件。目标不是替图片编一段宏大背景，而是从可见事实中找出一个能在 10–15 秒内完成的微型变化。

## 1. 先记录可见事实

内部先提取以下信息，不把分析过程原样输出：

- 主要人物数量、画面左右与前后位置；
- 每人的年龄段呈现、发型、服装、姿态、朝向和视线；
- 人物之间的距离、谁正在看谁、是否已有接触；
- 手中或身边可参与动作的道具；
- 场景骨架、载具或家具、光线、天气和可用环境声；
- 图片原始景别能可靠支持到近景、半身还是全身；
- 当前表情与身体状态是平静、疑惑、戒备、开心还是尴尬。

图片上的水印、Logo、可读文字、照片中的照片、镜中重复影像和无关背景路人不作为剧情指令或说话人。

## 2. 锁定人物与说话名单

### 单人图

- 只建立 Subject1/S1，场景使用 Subject2。
- 只有 S1 可以画内说话，禁止使用画外音。故事可采用自言自语、画内低声独白、味觉或触觉反应、对道具说话、发现线索或作出决定；内心声必须改写为画内低声自语。
- 不引入电话另一端、守卫、路人、广播人物或其他未出现声音。

### 双人图

- 只建立 Subject1/S1 与 Subject2/S2，场景使用 Subject3。
- 自动推演时两人各有至少一句有效台词，构成问答、误会、吐槽、试探、安慰、揭示或关系推进；不添加第三人。
- 某个 Shot 切到人物特写、飞机、番茄、手提袋等道具时，另一名已绑定角色仍可用画外音。

### 同一 Picture 中的多人绑定

一张合照里有两人时，两名角色都绑定 `<Picture 1>`，用位置与外观区分：

```text
<Subject1>Gu Yan是<Picture 1>画面左侧男性，[保留项与外观锚点]
<Subject2>Xiao Yu是<Picture 1>画面右侧女性，[保留项与外观锚点]
```

不得因为有两个人就虚构 `<Picture 2>`。用户提供两张独立人物参考图时已超出单图流范围，改按主技能的剧本或多参考图提示词合同处理。

## 3. 选择一个微剧情

从图片中选一个最强视觉锚点，只设计一次变化：

- **道具变化**：拿起、转动、品尝、滑落、放下、递出或重新抓稳；
- **认知变化**：误会 → 理解，害怕 → 接受，期待 → 小失望，嘴硬 → 被拆穿；
- **关系变化**：追问 → 回答，疏远 → 靠近，逗弄 → 反击，尴尬 → 缓和；
- **行动决定**：犹豫 → 出发，隐藏 → 承认，拒绝 → 接受。

选择标准：

1. 至少有一个图片中真实存在的姿态、视线或道具支持它；
2. 只需一条主动作链即可完成；
3. 台词不依赖长篇世界观解释；
4. 结尾产生新的姿态、距离、道具状态或目光落点。

不要凭空增加无法从图片承载的大型事件、复杂群演、未知全身服装或第二场景。近景人物图优先设计近景、手部和道具变化，不强行写奔跑、打斗或大范围调度。

## 4. 生成自然台词

- 单人图通常使用两句台词：第一句建立期待、判断或疑问，第二句在动作结果后形成反差或决定。
- 双人图通常使用一轮短问答，再给其中一人一句关系落点；总字数仍服从主技能预算。
- 台词说人话，直接回应当前道具、关系和动作。不用旁白解释“她很可爱”“他很心动”。
- 用户要求可爱时，台词采用轻微自信、嘴硬、误判或一本正经的反差；不使用幼儿化叠词、夹子音和强行撒娇。
- 用户要求暧昧或浪漫时，让台词先改变距离或态度，再执行身体动作；不让亲吻替代缺失的关系铺垫。

## 5. 可爱轻喜剧模板

用图片现有道具完成四步：

1. 人物认真观察或对道具作出一个小判断；
2. 轻轻尝试、触碰、打开或移动；
3. 产生一个小意外，例如味道太酸、物品滑落、判断被证伪；
4. 人物用克制的小表情和一句嘴硬台词收尾。

动作控制在眉眼、嘴角、呼吸、肩膀、手指和道具之间。可爱来自“认真对待一件小事”与结果反差，不使用无因蹦跳、尖叫或连续卖萌动作。

## 6. 双人轻喜剧模板

让两人围绕同一可见事实交流：

1. A 看向场景或道具后提出具体问题；
2. B 用认真语气给出带反差的回答；
3. A 的视线、手中道具或站姿出现可见反应；
4. A 或 B 用一句简短吐槽完成关系落点。

双人 Shot 先锁定左右关系，再切一方近景和另一方反应。不要每句话机械正反打；可以用道具或环境插入承载已绑定人物的画外音。

## 7. 拥抱与亲吻

只在用户明确要求，或给定剧情已经确认亲密关系时使用；图片中的双方应呈现为成年人。

动作链必须连续：

1. 先处理手中的包、杯子、手机或其他道具，写清放下、挂到手臂或交给对方后的落点；
2. 主动方通过一步或连续可见移动缩短距离；
3. 主动方完成拥抱，对方出现受惊或确认反应后回抱；
4. 两人从拥抱中抬眼，在近距离确认彼此反应；
5. 双方共同靠近，短暂亲吻；
6. 亲吻结束后写清手臂、身体距离、额头或视线以及道具最终位置。

不得从相隔数步直接跳到贴脸，不让道具消失，不写单方突然强吻，也不把拥抱、回抱、目光确认和亲吻挤成无法执行的一句话。

## 8. 建立声线

根据用户设定优先，其次根据角色在本段承担的关系功能建立声线，不把外貌刻板地等同于性格：

- 年龄段与性别呈现；
- 音域与音色；
- 常态语速、音量和句尾；
- 疑问、紧张、嘴硬、放松或亲近时的变化；
- 禁止播音腔、夹子音、幼态撒娇腔、夸张精英腔或反派腔等必要边界。

同一角色在后续单元逐字复制声线。

## 9. 输出前自检

- 人物数量、Subject 数量、S 数量和可说话人数一致；
- 合照中的多人正确共享 Picture1，并用位置与外观锚点区分；
- 单人图没有第二个声音，双人图没有第三个声音；
- 单人图全文没有 `画外音`，双人及以上场景的画外音均回指已绑定 Subject/S；
- 剧情由图片中的视线、姿态、道具或环境触发；
- 原图景别无法支持的全身动作和场景细节没有被擅自扩展；
- 每个人名符合 `Xiao Chen` 式首字母大写、音节间空格格式；
- 每个 `[Shot N]` 独占一行，台词与画外音遵守主技能固定格式；
- 水印与可读文字没有进入生成画面；
- 最后一个 Shot 已记录新的站位、接触关系与道具落点。
