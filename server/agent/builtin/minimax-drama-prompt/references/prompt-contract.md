# MiniMax 10–15秒剧本拆分与提示词合同

进入剧本划分、生成某段成品、批量输出或修改提示词时完整读取本文件。

## 完整读取与信息分流

完整读取剧本、人物设定、时间码、已经确认的分段和所有实际参考图。保留人物关系、事件顺序、关键事实、笑点、核心道具和情绪落点。

将信息分为五类：

1. 画内台词：人物在画面内完成口型。
2. 已绑定角色的OS、内心声和普通画外延续：两人及以上场景可用固定画外音格式；单人场景改为画内低声自语。
3. 临时功能人声：原作中只出现一次、只负责传令或必要信息的群演短句；最多一句，不超过20字，不建立固定声线，不与主要人物同时说话。
4. 未完成口播与停顿标记：保留有效信息；被打断、犹豫和停口转成可见动作、呼吸或对方介入，成品台词不使用省略号。
5. 字幕、论坛、聊天、片名和时间文字：作为后期节点，不要求视频模型直接生成。

原作时间码只表示叙事意图。若与自然表演或10–15秒上限冲突，重新估时，不靠快速念词硬塞。

## 划分10–15秒单元

每个单元只承载：

- 一个主场景；
- 一次微型关系变化；
- 一条主动作链；
- 一个明确出口。

先装满，再切分：

1. 先标记硬边界：场景或时空改变、主要人物绑定改变、动作链彻底结束，或关系完成不可逆转的转向。
2. 相邻硬边界之间默认按15秒组合连续剧情，优先装入36–44字有效台词及同步发生的一条动作链。
3. 合并后超过48字、出现两条互不依赖的主动作链，或自然表演明显无法在15秒完成时，才在回应完成、信息落地或动作结果处拆开。
4. 初步切分后反向检查：少于24字且只有简单动作的单元，先尝试并入前段或后段；只有相邻段已接近容量上限、存在硬边界，或该段依靠强动作、长停顿、悬念揭示独立成立时，才保留为10–12秒。

不要按台词行、单个问句或单个反应机械分段。默认保留“铺垫 → 回应 → 笑点或信息落点”的完整小回合；问句与直接回答不无故拆开，短促离场台词和转场画外音不单独占段。

用户未允许改词时只做自然分句；允许改编时不能改变人物意图、关键事实、笑点和关系结果。

### 台词预算

有效台词只统计实际说出口的汉字、字母和数字，不统计人物标签、标点、动作与Shot说明。

| 目标时长 | 建议台词 | 适用情况 |
|---|---:|---|
| 10秒 | 20–28字 | 强动作、明显停顿或无法跨越的短场景 |
| 12秒 | 28–36字 | 动作与对白接近均衡 |
| 15秒 | 36–44字 | 常规文戏、双人对话、连续轻喜剧问答 |

- 48字是硬上限。
- 达到45–48字时，台词必须短促清楚，动作链必须简单。
- 有口吃、哽咽、爆发、长停顿、亲密动作或复杂肢体动作时，减少约20%。
- 超载时依次处理：在关系转折处分段 → 在自然分句处分段 → 经用户允许压缩重复信息。

### 分段大纲格式

```markdown
# 分段大纲

- 总单元数：[N]个
- 预计总时长：[N]秒

1. P01｜[10/12/15]秒｜[段名]
   - 有效台词：[N]字
   - 事件：[本段发生什么]
   - 关系变化：[起始关系 → 结束关系]
   - 结尾落点：[动作、信息或姿态落点]
```

完整大纲输出后暂停并询问：`分段已完成，是否生成第一段提示词？` 不自动附带P01。

## Subject、Picture、英文名与场景

Subject、Picture和S一经确定，在整部作品中保持稳定。

- 每名角色使用 `<SubjectN>`，说话人编号使用对应 `SN`。
- 角色有独立参考图时，按输入顺序绑定 `<Picture 1>`、`<Picture 2>`。
- 一张合照中有多人时可以共享 `<Picture 1>`，必须用位置、发型、服装和外貌锚点区分，不得虚构 `<Picture 2>`。
- 没有实际参考图时不得写Picture，只使用文字人设映射。
- 英文名使用 `Xiao Chen` 格式：字母拼写、每个音节首字母大写、音节间一个半角空格。
- 场景使用人物Subject之后的下一个编号：一人场景用Subject2，两人场景用Subject3。

角色映射格式：

```text
<Subject1>Xiao Lin是<Picture 1>画面左侧女性，[外观锚点]，保留参考图中的面部特征、发型、服装、身材比例、眼镜与关键配饰。
```

没有参考图时改为：

```text
<Subject1>Xiao Lin是[剧本已经明确的文字人设]，人物外观在全片保持一致。
```

## 说话名单与声线

- 单人场景只建立Subject1/S1，只允许该人物画内说话，禁止画外音。
- 双人场景只建立Subject1/S1与Subject2/S2；已绑定人物暂时离开当前Shot时仍可用画外音。
- 原作明确的一次性功能角色可以使用一条临时环境人声；需要正面表演、连续说话或后续再次出现时必须正式绑定。
- 同一时刻只有一人说话，倾听者闭口并给出由具体台词触发的可见反应。

第一次处理作品时，为每名主要角色建立固定声线，包含年龄段与性别呈现、音域与音色、常态语速与音量、句尾习惯、受压或放松后的变化和负向边界。后续逐字复制同一声线，当前情绪只写在Shot表演中。

声线格式：

```text
<Subject1>，S1 永远是说话人。S1始终使用一种固定的声音：[完整声线]。
```

## 人物站位与连续性

角色和声线块之后、`[Shot 1]`之前固定输出一段人物站位。人物站位不是Shot，不占时长。

写清：

- 场景、时间、机位轴线与人物左右关系；
- 每名角色的纵深、姿态、朝向、视线和起始距离；
- 服装、核心道具及其持有人与状态；
- 会影响动作的门窗、家具、载具、光线和环境声。

新场景重新建立站位。同场连续单元从上一段末帧完整复位，不只写“承接上一段”。人物换边、靠近、离开和道具转移通过可见动作完成。

## Shot设计

10秒使用2–3个有效Shot，12秒使用3–4个，15秒使用3–5个。

- `[Shot 1]`直接启动动作、台词或环境触发，不重复建立站位。
- 每个Shot标签独占一行，下一行才写内容。
- 每个Shot按“主体与景别 → 一个主导动作 → 1–3个配合信号 → 台词或声音”书写。
- 只有出现新信息、说话权、人物距离、道具状态、行动结果或有效反应改变时才切镜。
- 默认稳定机位直接切换景别；一个单元最多一次有叙事作用的推、移或跟拍。
- 空镜与道具插入承接正在运行的动作、声音或物理后果；切画面不等于故事暂停。
- 最后一个Shot明确人物位置、姿态、视线、接触关系与道具状态，供下一段复位。

## 台词与画外音格式

画内台词严格分成两行：

```text
<Subject 1> (S1) says:
<d>[Chinese][完整台词]</d>
```

两人及以上场景中，已绑定角色画外音严格分成三行：

```text
画外音
<Subject 2> (S2) says:
<d>[Chinese][完整台词]</d>
```

`画外音`独占一行，不添加冒号、人物名、“继续”或可见性解释。成品台词不使用省略号；停顿和打断写进动作。

一次性功能角色环境人声格式：

```text
[Shot N]
[主要角色、门口、走廊或环境镜头]。[主要动作继续运行]。环境中一名[临时角色身份]低声说：“[不超过20字的必要信息]。”
```

## 固定交付合同

提示词外先写单元标签：

```markdown
## P01｜15秒｜[段名]
```

正文顺序固定为：角色映射 → 对应声线 → 场景Subject → 人物站位 → 连续Shot → 固定尾部。不要增加全局说明、剧情分析、固定台词或声音设计等顶层字段。

双人正文骨架：

```text
<Subject1>Xiao Lin是[角色映射]。
<Subject1>，S1 永远是说话人。S1始终使用一种固定的声音：[声线全文]。

<Subject2>Xiao Chen是[角色映射]。
<Subject2>，S2 永远是说话人。S2始终使用一种固定的声音：[声线全文]。

<Subject 3>是[场景名称]场景。

人物站位：[可执行站位与道具状态]。

[Shot 1]
[主体、景别、动作与表演]：
<Subject 1> (S1) says:
<d>[Chinese][完整台词]</d>

[Shot 2]
[倾听反应、道具变化或关系动作]：
<Subject 2> (S2) says:
<d>[Chinese][完整台词]</d>

[Shot 3]
[动作结果与末帧状态]。

【禁止项】

文字/UI/水印/Logo/角标/可读文字/真实UI

【强制声明】

无背景音乐,仅保留环境音与人声和音效;画面禁字幕/文字/水印/Logo;禁止可读文字(指画面字幕文字,不含人声台词)
```

单人正文骨架：

```text
<Subject1>Xiao Lin是[角色映射]。

<d>[Chinese][完整台词]</d>

【禁止项】

文字/UI/水印/Logo/角标/可读文字/真实UI

无背景音乐,仅保留环境音与人声和音效;画面禁字幕/文字/水印/Logo;禁止可读文字(指画面字幕文字,不含人声台词)
```

【禁止项】与【强制声明】必须逐字复制，不扩写、不缩写、不改标点、不调整顺序。全文不添加背景音乐、歌曲或配乐。

## 完整重发规则

用户修改任何Shot、台词、声线、站位、道具或画外音时，从第一条角色映射开始完整重发该单元，直到固定尾部。只有用户明确要求“只发修改部分”时才局部输出。

## 交付前检查

- 时长、台词预算、关系变化和动作链匹配；
- 少于24字的简单单元已经执行合并检查；
- Subject、Picture、S、英文名与声线稳定；
- 没有虚构Picture，没有无过程跳位或道具消失；
- 每个Shot标签独占一行并连续编号；
- 台词和画外音格式正确，没有省略号；
- 最后一个Shot记录可复位的末帧；
- 固定尾部逐字一致，全文没有背景音乐。
